# Code of Conduct

## Expected Behavior

- Be direct and respectful.
- Keep discussion technical and task-focused.
- Assume contributors are trying to improve the project.
- Critique ideas, implementation, and evidence rather than people.

## Unacceptable Behavior

- Harassment, threats, or discriminatory language.
- Personal attacks.
- Spam or unrelated promotion.
- Publishing private information without consent.

## Reporting

Report conduct issues to the repository maintainers through the contact method
listed in the repository profile or via a private security report if the issue
also affects project safety.

Maintainers may remove content, close discussions, or restrict participation
when needed to keep the project usable.
