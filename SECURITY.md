# Security Policy

## Reporting

Please report security issues privately rather than opening a public issue.

Relevant issues include:

- Malicious prompt-injection in source chunks or skill text.
- Unsafe behavior in `scripts/install.sh`.
- Source tampering or misleading provenance.
- Validation bypasses that could install malformed skills.

Do not include exploit details in public issues. Provide the affected file,
impact, and a minimal reproduction in the private report.

## Scope

This repository contains documentation, skills, and local scripts. It does not
run a hosted service.
